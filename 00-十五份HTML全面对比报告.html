Executive verdict

没有绝对最好，只有角色分工

把 Codex CLI 作为主版本；ChatGPT 复习，Gemini 3.1 Pro 摘要，Gemini 3.6 Flash 扩展，Claude Code 深挖。

只保留一组

选 Codex CLI。它在内容、证据、篇幅、语义结构、移动适配与可维护性之间最均衡。

技术质量冠军：ChatGPT / Codex 并列。内容深度冠军：Claude Code。3.6 Flash 先修移动端，3.1 Pro 先补事实与离线能力。

Generator profiles

五种生成方式的稳定性格

这里的分数把“内容质量”和“技术健康”分开，避免视觉更华丽就自动获胜。

ChatGPT 客户端 · 快速版

短、稳、决策清楚

22/25 内容
  • 每篇约 3,745–5,169 正文字符
  • 决策地图与最小心智模型最直接
  • 完全离线，390px 无溢出
  • Claude 权限边界解释最好
最适合：第一次快速建立框架、10 分钟复习
Claude Code · 深度版

深、密、图示丰富

20/25 内容
  • 每篇约 15,710–18,131 正文字符
  • 搜索空间与解释深度最高
  • Mermaid 图最多、叙事类比最强
  • 移动溢出、外部依赖与维护成本较高
最适合：深度研读、作为主版本的补充材料
Codex CLI · 主版本

结构、证据、篇幅最均衡

23/25 内容
  • 每篇约 4,661–6,500 正文字符
  • 语义 landmarks 每页 16 个
  • 参数页覆盖 37 个不同 flags
  • 来源链接与世界模型组织最好
最适合：长期保留、正式讲解、作为统一主版本
Gemini 3.6 Flash · 扩展版

完整、展开、结构稳定

21/25 内容
  • 每篇约 5,508–6,539 正文字符
  • 十个板块与三层概念组织完整
  • 完全离线，标题层级与 landmarks 良好
  • 三页移动端均宽到 710px
最适合：从主版本向专家问题扩展的第二视角
Gemini 3.1 Pro · 视觉摘要版

最短、醒目、移动端友好

17/25 内容
  • 每篇约 2,521–2,849 正文字符
  • 390px 无横向溢出，页面最短
  • 核心隐喻和 Mermaid 关系图醒目
  • 参数页仅 2 flags，且依赖外部资源
最适合：快速浏览、讲解后的视觉复盘

Method & limits

怎么得出这些结论

测量方法

静态扫描文件大小、正文字符、标题、语义标签、参数覆盖与来源链接；用本机 Chrome 在 1440×1000 和 390×844 下检查 HTTP、console、失败资源、横向溢出和运行时 Mermaid 错误；再做十五页视觉复核。

来源归因限制

ChatGPT 客户端及两个 Gemini 组由用户或当前任务历史确认。Codex CLI 与 Claude Code 两组依据创建时间、资产结构、命名方式和实现指纹，属于高置信归因。
