Claude 代理参数 (CLI Parameters)

1. Essence (本质)

What is it fundamentally?

CLI 里的参数并非简单的“设置选项”，而是你在为一个“自治认知引擎(Agent)”设定上下文边界、行为法则和能力范围。它们是控制大模型物理（Token）和精神（Persona）状态的杠杆。

Why does it exist?

因为大模型本身是无边界、无状态的。必须通过参数显式注入工作记忆(Context)与边界(System Prompts)，它才能在特定任务空间中有效工作。

What problem does it solve?

解决了模型幻觉、缺乏特定项目背景知识、以及认知漂移的问题。将宽泛的聊天机器，收束为精确的任务执行器。

3. Concept Map (概念图谱)

mindmap root((Agent 核心约束)) 身份层 System Prompt (角色与元指令) Rules (限制边界) 认知层 Model Selection (思考深度与速度) Temperature (发散思维 vs 聚合收敛) 记忆层 Context Load (挂载上下文文件) Token Limit (注意力跨度)
Memory (记忆层参数)

Action: 将特定文件/信息挂载到 Context Window。Purpose: 给予 AI 解题所必须的背景知识（如代码库结构），消除信息差。

Identity (身份层参数)

Action: 定义 System Prompt 规则。Purpose: 剥夺模型发散聊天的权限，将其行为框定在“资深工程师”或“严谨校对员”的范式内。

4. Decision Map (决策图谱)

Situation: 需要修改一个横跨多个文件的复杂 Bug

Decision: 宽上下文 + 慢思考模型 (High-tier Model) + 权限注入。
Reason: 需要建立庞大的代码依赖心理模型，并在本地真实环境迭代执行。
Outcome: 精准且一次成型的重构。

Situation: 编写一段纯粹的基础算法（如快排）

Decision: 零上下文 + 快思考模型 (Fast-tier Model)。
Reason: 标准知识在模型预训练权重中已有完美映射，额外上下文只会增加噪音和延迟。
Outcome: 毫秒级输出标准解。

Situation: 创作营销文案或头脑风暴

Decision: 调高 Temperature / 随机性参数。
Reason: 需要绕过高频词汇的常规路径，寻找概率分布长尾中的创造性组合。
Outcome: 内容的涌现和惊喜感。

5. Search Space Expansion (认知空间拓展)

  • Beginner (很少问的问题): “传给 AI 的文件，它是怎么看到的？” (引出 Token 化与注意力机制的概念)
  • Expert (专家关注): “在这个上下文中，Signal-to-Noise Ratio (信噪比) 足够高吗？无用信息会不会稀释模型对关键指令的注意力？”
  • Next to explore (值得探索): 工具调用(Tool Use/Function Calling) 参数是如何让 AI 突破文本界限，真实操作我的文件系统的？
  • Mastery (大师级): 动态 Context 管理——在长会话中，如何让系统像人类一样遗忘无关细节，提纯并保留核心记忆。

6. Ecosystem (生态系统)

  • Upstream (上游): LLM 供应商 (Anthropic, OpenAI)、本地模型 (Ollama)。
  • Downstream (下游): IDE (VSCode, Cursor), 本地终端环境, 代码库状态。
  • Complements (互补系统): 向量数据库 (RAG 检索增强)、静态代码分析工具 (生成精确上下文)。

7. Transferable Principles (可迁移原则)

1. Context is King (上下文即一切)

AI 的表现 90% 决于你通过参数挂载了什么上下文。不要指望它猜透你的未言之意。

2. 意图的显式降维 (Explicit Framing)

System Prompt 参数本质上是将人类模糊的多维意图，降维锁定到一条清晰的单维准则线上。

3. 认知资源分配法则 (Cognitive Economics)

Token 是有限且昂贵的认知资源。参数管理的本质就是 Token 的最优经济分配（给更多背景，还是留更多空间生成答案）。

8. Minimum Mental Model (最小记忆模型)

控制 AI 的黄金法则可以抽象为：

  • Engine (是谁思考): Model 参数决定了思考者的智力上限和响应速度。
  • Directive (听谁指令): System Prompt 构成了不可违背的“第一定律”。
  • Context (看什么资料): Files/Dir 参数将静态资料变为模型当前工作流的即时输入流。

9. Common Misconceptions (常见误区)

Misconception: 传给 AI 的文件/信息越多越好。

Why: 人类习惯于“资料齐全”。
Better Model: 模型的“注意力窗口”存在极限。过载的上下文会导致“中间丢失现象(Lost in the middle)”。精准的 Context 切片，胜过丢进去一整个仓库。

What I truly gain is not memorizing a list of terminal flags (--context, --model), but

The framework to orchestrate and bound autonomous cognitive labor.

(我真正获得的不是死记硬背终端参数，而是能够精密编排和约束自主认知劳动力(AI)的心智框架。)
